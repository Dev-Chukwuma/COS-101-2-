# Multilingual Translation System

## Project Description

A Python application that translates 20 English words and phrases into five Nigerian languages: Igbo, Hausa, Yoruba, Idoma, and Tiv.

## Features

- Language selection
- Translate individual words
- Display available English words
- View all translations
- Change selected language
- Interactive menu

## Technologies Used

- Python
- Git
- GitHub
